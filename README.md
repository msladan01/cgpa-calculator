
# 🎓 CGPA Calculator
A simple Python-based CGPA calculator for Nigerian University grading system (5.0 scale). Built as a 200L Computer Science project.

## Features
- Supports 5.0 grading system (A=5, B=4, C=3, D=2, E=1, F=0)
- Calculates CGPA based on course units and grades
- Clean CLI interface

## How to Use
python cgpa.py
